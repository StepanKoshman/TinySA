# TinySA Studio

Современная ПК-программа для **TinySA Ultra** (работает и с базовым TinySA):
спектр + водопад, маркеры, измерения, генератор, запись, консоль.

## Запуск
```bash
pip install -r requirements.txt
python tinysa_studio.py
```
Без прибора нажмите **«Демо»** — программа покажет имитацию сигналов (FM, ISM, GSM, ADS-B, Wi-Fi).
Windows: драйвер не нужен (USB-CDC), порт выбирается автоматически по VID/PID 0483:5740.
Linux: `sudo usermod -aG dialout $USER` и перелогиниться.

## Возможности
| Раздел | Что есть |
|---|---|
| Спектр | Live / Max hold / Min hold / Среднее (N сканов), заливка, dBm ↔ dBµV, авто-шкала Y |
| Водопад | 5 палитр, авто/ручные уровни, история до 2000 строк, общая ось X со спектром |
| Развёртка | Старт/Стоп/Центр/Полоса (ввод `433.92M`, `2.4G`), пресеты диапазонов, кнопка «= видимая область» |
| Разрешение | До 5000 точек: скан автоматически режется на сегменты по ≤450 точек (весь диапазон 0.1 МГц – 6 ГГц) |
| Вход | RBW, аттенюатор, LNA, spur removal, Low/High input (авто по частоте) |
| Маркеры | 4 шт., двойной клик по графику, перетаскивание, Δ к M1, M1 следит за пиком, «Центр = M1», «Диапазон M1–M2» |
| Пики | Таблица 8 сильнейших пиков, двойной клик → маркер |
| Измерения | Мощность в полосе, пик в полосе, OBW 99 %, шумовой пол |
| Порог | Линия порога, индикация превышения, звук |
| Генератор | Частота, уровень, AM/NFM/WFM (развёртка на время работы останавливается) |
| Запись | Лог каждого скана в CSV (время + уровни), экспорт трасс CSV, PNG графиков/водопада |
| Прибор | Скриншот экрана (`capture`), напряжение батареи, консоль с историей команд |
| Настройки | Автосохранение, экспорт/импорт JSON |

Горячие клавиши: `Space` старт/стоп, `M` пик → M1, `Ctrl+R` сброс, `Ctrl+S` CSV, `Ctrl+P` PNG.

## Важно (калибровка)
Уровень считается как `dBm = raw/32 − scale`. Для Ultra `scale = 174`, для базового tinySA `128`
(подставляется автоматически, правится во вкладке «Развёртка»). Если уровни отличаются от экрана прибора —
подстройте «Шкала» или «Смещение уровня».

## Протокол
`scanraw <start> <stop> <points>` (бинарный ответ `{ 'x'+uint16 ... }`), плюс `rbw`, `attenuate`, `lna`, `spur`,
`mode low|high input|output`, `freq`, `level`, `modulation`, `output`, `vbat`, `capture`, `pause/resume`.
Синтаксис команд зависит от версии прошивки — любую команду можно проверить во вкладке «Консоль» (`help`).

## Сборка в .exe
```bash
pip install pyinstaller
pyinstaller --noconsole --onefile --name TinySAStudio tinysa_studio.py
```
